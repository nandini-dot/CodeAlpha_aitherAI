# 🌌 AetherAI Semantic FAQ Chatbot

An intelligent semantic FAQ chatbot built using pure Python, custom NLP preprocessing, TF-IDF vectorization, and cosine similarity matching — all wrapped inside a modern glassmorphism-inspired web interface.

---

# 🚀 Project Overview

AetherAI is a lightweight AI-powered FAQ assistant designed to answer user questions intelligently using semantic text similarity instead of exact keyword matching.

The project was built with two major goals:

- Create a fully offline NLP-based chatbot without heavy machine learning dependencies.
- Deliver a beautiful, modern, interactive user interface with smooth animations and responsive design.

---

# ✨ Features

## 🧠 Intelligent Semantic Matching
- Custom TF-IDF implementation
- Cosine similarity matching
- Semantic token enrichment
- Suffix stemming support
- Noise-word filtering

## 🎨 Modern UI Design
- Glassmorphism sidebar
- Floating animated gradients
- Soft-entry message animations
- Typewriter response effect
- Match score banner

## ⚡ Lightweight & Offline
- No heavy ML frameworks
- Pure Python implementation
- Fast local processing
- Runs completely offline

## 💾 Interactive Features
- Chat history caching
- FAQ category navigation
- Search filtering
- NLP preprocessing simulator
